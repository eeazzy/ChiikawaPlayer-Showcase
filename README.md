## ✨ 작지만 편한 기능들

| 기능 | 이렇게 사용해요 |
| :--- | :--- |
| 🔎 회차 검색 | 보고 싶은 회차를 빠르게 찾아요. |
| ⏭️ 엔딩 자동 넘김 | 설정된 엔딩 시간에 맞춰 3초 뒤 다음 회차로 이어져요. 계속 보고 싶으면 취소할 수 있어요. |
| ↔️ 이전 화·다음 화 | 목록을 다시 찾지 않아도 회차를 바꿀 수 있어요. |
| 📱 모바일·전체 화면 | 컴퓨터에서도, 휴대폰에서도 편하게 봐요. |
| 🌼 가볍게 시작 | 공개된 회차는 로그인 없이 볼 수 있고, 시청 기록은 저장하지 않아요. |
